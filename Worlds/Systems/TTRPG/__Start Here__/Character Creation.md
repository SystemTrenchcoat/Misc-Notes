First things first: You have 4 free skills. They can be the first leaf of any tree, or any leaf within [[Adaptation.canvas]]. If a leaf has a purple border, it costs 2 skills.

You then get 20 [[Skill Points]] (not to be confused for skill pills) to use as you see fit. Each leaf has a listed cost. When you select that leaf, subtract the cost from your total and keep going until you have the skills you want, or run out of points. The GM can choose to change the number of [[Skill Points]] if they so desire.

The main skill trees are:

- [Adaptation](Adaptation.canvas)
- [Combat](Combat.canvas)
- [Crafting](Crafting.canvas)
- [Exploration](Exploration.canvas)
- [Social](Social.canvas)
- [Spellcasting](Spellcasting.canvas)

The remaining skill trees each correspond to a power that makes up the world of Eotal.
